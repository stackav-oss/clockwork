# Real-time playback policy

`RealtimePlaybackPolicy` marks a destination channel as supplied by a distributed real-time log player.
The policy target remains the destination channel; no runtime publishers or conversion artifacts are generated by this policy alone.

- `source_name` defaults to the destination channel name.
- `playback_cpu_domain` is required and must name a `CpuDomain` in the selected
  physical system.
- `stream_kind` defaults to `regular`; use `camera` for camera playback.

The open-source bundle converter owns regular and initialization conversion.
Camera conversion is supplied as a `CameraConverterFunction` by the application.
A bundle with camera assignments fails if the application does not supply that function; bundles without camera
assignments do not require one.

```clk
use clockwork::logging::realtime_playback::realtime_playback_policy::{RealtimePlaybackPolicy};
use clockwork::logging::realtime_playback::realtime_playback_stream_kind::{RealtimePlaybackStreamKind};

policy RealtimePlaybackPolicy for vehicle::Localization
{
  playback_cpu_domain = vehicle::PlaybackDomain;
}

policy RealtimePlaybackPolicy for vehicle::FrontCamera
{
  source_name = '/recorded/front_camera';
  playback_cpu_domain = vehicle::PlaybackDomain;
  stream_kind = RealtimePlaybackStreamKind::camera;
}
```
