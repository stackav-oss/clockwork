# Jewels

`jewels` are re-usable software libraries to support the development of high quality AV software.
Like the jewel bearings in a clock, `jewels` lower the friction of software development.

## Jewel summary

- `aligner`: buffer alignment tools.
- `callsig`: tools to implement function calling conventions (return codes and output parameters).
- `cli`: functionality for CLI applications.
- `compiler`: abstractions for compiler directives in source code.
- `container`: fixed-size container classes.
- `filesystem`: utilities for filesystem operations.
- `hash`: functionality to compute hashes with common hashing algorithms.
- `log_cerr`: logging infrastructure to log to `cerr` with various log levels.
- `math`: convenience functions for math operations.
- `memory`: memory management.
- `meta`: templates to simplify C++ metaprogramming.
- `nanobind`: conversions between C++ and Python types.
- `networking`: convenience functions for interacting with network sockets.
- `scope_guard`: class that calls a user-provided function on destruction.
- `shared_pool`: non-thread-safe pool of reference-counted objects.
- `testing`: utilities to aid in jewel unit testing.
- `time`: abstractions for synchronized and unsynchronized (monotonic) time bases.
- `units`: a library for physical units based on [Au](https://aurora-opensource.github.io/au/0.3.2/))
- `utility`: utilities for treating Enumerations as flag values.
- `uuid`: tools to generate and manipulate Universally Unique Identifiers.
