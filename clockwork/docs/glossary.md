# Glossary

| Clockwork Term | Definition                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------ |
| Channel        | Mechanism used to pass messages between Cogs.                                                    |
| Clockwork      | Stack's in-house production-intent robotics software infrastructure.                             |
| Cog            | A fundamental executable unit of a Clockwork system.                                             |
| Dial           | Structure provided to Cogs for execution, including the inputs, output, diagnostics handle, etc. |
| Interface      | Language-specific API to work with schema instances.                                             |
| Module         | A group of Cogs and other modules (i.e., a module may contain other modules hierarchically).     |
| Node           | Physical machine in the system.                                                                  |
| Pinion         | Clockwork's underlying message-passing layer.                                                    |
| Representation | Concrete realization of a schema in memory, storage, or network.                                 |
| Runner         | Executes a subset of a System. There are two main runners: Online and Offline.                   |
| Schema         | An abstract data type specification for structured data.                                         |
| System         | A group of Modules.                                                                              |
